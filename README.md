        <h1>E-Library Management System</h1>
        <p>A fully automated E-Library Management System designed for efficient management of books and library resources, featuring dedicated Admin and User Panels.</p>
        <hr>
        <h2>🚀 Features</h2>
        <h3>Admin Panel</h3>
        <ul>
            <li>Add, edit, and delete <strong>Books</strong>, <strong>Authors</strong>, <strong>Publishers</strong>, <strong>Shelves</strong>, <strong>ISBN numbers</strong>, etc.</li>
            <li>Generate multiple reports related to books, authors, publishers, and more.</li>
            <li>Manage <strong>book issues</strong> and generate reports for students, teachers, and staff.</li>
            <li>Implement an <strong>automatic fine system</strong> for late book returns or lost books.</li>
            <li>Add <strong>Audio Books</strong>, <strong>Magazines</strong>, and <strong>Research Papers</strong>.</li>
            <li>Upload <strong>Video Lectures</strong>.</li>
            <li>Define and manage <strong>fine rules</strong> for late returns.</li>
        </ul>
        <h3>User Panel</h3>
        <ul>
            <li>Search, view, and reserve books.</li>
            <li>Read and download <strong>e-books</strong>, <strong>magazines</strong>, and <strong>research papers</strong>.</li>
            <li>Receive <strong>automatic reminders</strong> for book returns via email before the due date.</li>
            <li>View personal <strong>book issue history</strong>.</li>
            <li>Add books to the <strong>cart</strong> for easier management.</li>
            <li>Stay updated with the latest library <strong>news and updates</strong>.</li>
            <li>Provide feedback through a dedicated option.</li>
        </ul>

        <h2>🛠️ Installation</h2>
        <ol>
            <li>Clone the repository: <pre><code>git clone https://github.com/your-username/e-library-management-system.git</code></pre></li>
            <li>Navigate to the project directory: <pre><code>[cd e-library-management-system]</code></pre></li>
            <li>Run Command: <pre><code>[php artisan composer update]</code></pre></li>
            <li>Set up the database with name elibrary and configure your environment variables.</li>
            <li>Migrate the database: <pre><code>[php artisan migrate]</code></pre></li>
            <li>Run the project: <pre><code>[php artisan serve]</code></pre></li>
        </ol>
